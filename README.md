# AnimatorApp
A general purpose animation software that is inspired by Blender in java.
# Scope
The `core` module is the independent kernel that can be used for any kind of application context that requires UI, user interaction and a datamanagement system. Any general purpose utils or frameworks go into core.
<br><br>
The `app` module is the application with concrete implementations of the core frameworks like: user interaction logic, concrete UI for the animation software and the application data model.
